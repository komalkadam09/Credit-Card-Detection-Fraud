# Credit Card Fraud Detection using Machine Learning

## Project Description

This project detects fraudulent credit card transactions using Machine Learning algorithms.

The dataset is taken from Kaggle and contains information about genuine and fraudulent transactions.

## Algorithms Used

- Logistic Regression
- Random Forest Classifier

## Libraries Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Imbalanced-learn

## Dataset

- fraudTrain.csv
- fraudTest.csv

## Project Workflow

1. Load Dataset
2. Data Preprocessing
3. Encode Categorical Data
4. Split Dataset
5. Apply SMOTE
6. Train Machine Learning Model
7. Predict Fraud Transactions
8. Evaluate Model

## Results

Random Forest performed better than Logistic Regression.

Accuracy Achieved:
99.37%
